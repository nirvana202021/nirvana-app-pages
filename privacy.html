プライバシーポリシー

本ポリシーは、個人事業主 NIRVANA（以下「当方」）が運用するツール「NIRVANA uploader」（以下「本ツール」）における情報の取り扱いを定めるものです。

1. 本ツールの利用者

本ツールは当方の事業主本人のみが使用する非公開ツールであり、第三者に提供していません。したがって、当方以外の利用者の情報を収集することはありません。

2. アクセスする Google ユーザーデータ

本ツールは、Google ドライブ API を通じて、利用者本人（＝当方）の Google ドライブに対し、フォルダの作成およびファイルのアップロードを行います。使用する権限は Google ドライブへのアクセス権限のみです。

3. 取り扱う情報

本ツールが扱うのは、当方が運営する eBay 販売アカウントの月次取引レポート（CSV 形式）です。当該ファイルは、当方の Google ドライブ内の当方が指定したフォルダにのみ保存されます。

4. 情報の利用目的

取得した情報は、当方の記帳、経理処理および税務申告の目的にのみ使用します。それ以外の目的には使用しません。

5. 第三者提供

当方は、Google から取得したユーザーデータを第三者に販売、譲渡、貸与しません。ただし、当方の税務申告を代行する税理士に対して、当方の判断により当該レポートを共有することがあります。

6. 保管と削除

アップロードしたレポートは、法令で定める帳簿書類の保存期間にわたり当方の Google ドライブ内に保管します。認証情報（アクセストークン）は本ツールを動作させる当方の管理下の機器にのみ保存し、外部へ送信しません。不要になった時点で削除します。

7. 安全管理

認証情報は当方が管理する機器上に、本人以外が読み取れない権限設定で保存します。通信はすべて暗号化された経路（HTTPS）で行います。

8. Google API サービスのユーザーデータに関するポリシーの遵守

本ツールによる Google API から受け取った情報の使用および他アプリへの移転は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

9. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更することがあります。変更した場合は本ページに掲載します。

10. お問い合わせ

本ポリシーに関するお問い合わせは、Google の同意画面に表示されるサポート用メールアドレス宛にご連絡ください。
